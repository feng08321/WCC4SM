WCC4SM V0.5
Date: 2026-07-30

Main update
-----------
The calibrated-performance FWHM histogram now supports manual plotting
parameters:

1. Bins
   Sets the histogram bin count from 1 to 100.

2. X min / X max
   Set the displayed histogram boundary in nanometres.

3. Auto full / Manual
   Auto full uses the complete valid FWHM range with a small visual margin.
   Manual uses the entered X min and X max as the histogram BinLimits.

4. Refresh
   Recalculates and redraws the calibrated-performance page.

Statistical definition
----------------------
N, Mean, Median, STD and Range continue to use all confirmed valid
wavelength-domain FWHM values. In Manual mode, only the histogram bars are
limited to the selected interval. The plot reports both the complete sample
count (N) and the number of samples displayed inside the manual interval.

Other retained functions
------------------------
- All plot tabs remain available through the unified OPEN FIG selector.
- The other three Calibrated Performance plots are unchanged.
- Calibration fitting, residual analysis, validation and model comparison
  logic are unchanged.
