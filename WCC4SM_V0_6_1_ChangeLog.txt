WCC4SM V0.6.1
Date: 2026-08-03

Usability and coordinate-model update
-------------------------------------
1. Improves header workflow-status contrast and reserves a dark background.
2. Shows live dashed start/end markers on the main spectrum while the weak-peak
   subwindow dialog is open. Markers follow pixel edits and the applied
   wavelength axis, and are removed when the dialog closes.
3. Replaces the ambiguous 0/1 Natural pixel start control with two explicit,
   one-based acquisition modes:
   - Full detector sequence: an uncalibrated instrument exposes all pixels.
   - Valid-pixel sequence: a calibrated instrument outputs only its usable
     cropped sequence.
4. Stores the pixel-coordinate mode, data domain and calibration domain in each
   new final model. Applying a model from a different explicit mode is rejected
   instead of silently shifting its coefficients. V0.6.0 legacy models without
   coordinate metadata remain loadable.
5. Removes the duplicate Calibration Fit button for the combined residual
   popup. Embedded plots and the header OPEN FIG workflow remain available.
6. Adds two session-validation tests for coordinate metadata and invalid modes.
7. Fixes subwindow guide-line accumulation in MATLAB R2022a by explicitly
   deleting hidden guide objects before every redraw. Pixel/wavelength axis
   switching now resets X/Y limits to automatic fitting so an earlier guide or
   zoom cannot retain the previous coordinate domain.

Compatibility
-------------
WCC4SM_V0_6_0.m is unchanged. Session format major version remains 1. Existing
V0.6.0 sessions and models are treated as legacy natural-pixel coordinates.

Validation
----------
Run run_wc4sm_tests and complete a GUI smoke test for both pixel-sequence modes,
subwindow marker updates, model application and session round-trip.
