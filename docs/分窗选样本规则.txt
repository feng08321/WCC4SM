# 一、功能总体结构

规则子样本生成拆成两个独立步骤：

Step 1：Window Partition
    ↓
用户检查分窗结果
    ↓
Step 2：Within-window Sample Selection

第一版只实现 Step 1。

用户输入：

1. Target sample count / Window count: K
2. Partition rule:
   - Equal wavelength width
   - Equal cumulative influence weight

原则上：

Window count = K

例如 K = 6，则生成：

W1, W2, ..., W6

每个窗口最终在第二阶段选择1个代表样本，因此最终形成6点定标子集。

但当前第一版不要自动选择代表点。

==================================================
# 二、规则A：等波长宽度分窗
==================================================

设有效样本参考波长范围：

λ_min = min(λ_i)
λ_max = max(λ_i)

用户指定：

K = 6

则理论窗宽：

Δλ = (λ_max - λ_min) / K

窗口边界：

b_j = λ_min + j Δλ

j = 1,2,...,K-1

因此：

W1 = [λ_min, b_1)
W2 = [b_1, b_2)
...
WK = [b_(K-1), λ_max]

边界点归属规则保持确定性：

左闭右开，最后一个窗口右端闭合。

即：

W_j = [b_(j-1), b_j)

最后：

W_K = [b_(K-1), λ_max]

该规则作为纯“波长空间均匀覆盖”的基准方法。

==================================================
# 三、规则B：等累计Influence权重分窗
==================================================

这个规则不是按照波长长度等分，而是按照三阶模型下的 Deletion Influence 累计权重等分。

目的：

让每一个窗口承担近似相同的累计样本影响权重。

注意术语：

这里称：

Cumulative influence weight

不要称为 information quantity，因为 deletion influence 并不是严格可加的信息量。

## 3.1 按波长排序

首先将有效样本按照参考波长升序排列：

λ_1 < λ_2 < ... < λ_N

对应三阶模型的 deletion influence：

I_1, I_2, ..., I_N

Influence 应满足：

I_i >= 0

## 3.2 归一化Influence

计算总Influence：

I_total = Σ I_i

归一化：

w_i = I_i / I_total

因此：

Σ w_i = 1

## 3.3 累计Influence

定义：

F_i = Σ_(j=1)^i w_j

于是：

F_N = 1

用户指定 K 个窗口，例如：

K = 6

理想累计权重分割位置为：

q_j = j / K

即：

1/6
2/6
3/6
4/6
5/6

目标是寻找 K-1 个实际样本间隙，使每个窗口的累计 Influence 尽量接近：

1/K

也就是约1/6。

==================================================
# 四、离散样本条件下的分割边界确认
==================================================

这是该算法的重要部分。

Influence 是定义在离散谱线上的，不能真正从某一个样本中间把权重切开。

因此：

“窗口边界只能位于两个相邻参考样本之间”。

对于目标累计位置：

q_j = j/K

寻找相邻样本 i 和 i+1，使：

F_i <= q_j <= F_(i+1)

此时有两个候选切法：

Candidate A:
在样本 i 后切分

Candidate B:
在样本 i+1 后切分
（实际实现时需要保证后续窗口仍至少含一个样本）

优先选择使累计Influence最接近 q_j 的切分位置：

min |F_i - q_j|

如果前后两种切法的累计Influence误差非常接近，则使用“波长间距”作为第二判据：

Δλ_i = λ_(i+1) - λ_i

优先在较大的自然峰间距处切分。

也就是说：

一级判据：
累计Influence分割误差最小

二级判据：
优先选择较大的相邻波长Gap

这样既尽量实现“等累计权重分窗”，又尽量避免人为切开一个天然密集谱线簇。

## 4.1 实际边界坐标

确定样本 i 属于左窗、样本 i+1 属于右窗以后，显示边界位置：

b_j = (λ_i + λ_(i+1)) / 2

注意：

该 b_j 仅作为可视化窗口边界。

真正的样本归属由 cut index 决定：

样本 i → 左窗
样本 i+1 → 右窗

不能仅靠浮点波长与 b_j 比较重新决定归属。

## 4.2 特殊情况

如果某一个单独样本：

w_i > 1/K

则它自身已经超过一个理想窗口的累计Influence份额。

第一版不要自动把它变成 Anchor，也不要进行复杂重分配。

只按照“累计误差最小”原则决定边界，并在结果中增加提示：

Dominant influence sample

记录：

Peak ID
Reference wavelength
Normalized influence w_i

后续再根据实际结果决定是否引入 Anchor Window 机制。
