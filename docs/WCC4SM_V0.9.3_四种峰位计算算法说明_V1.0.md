# WCC4SM V0.9.3 四种峰位计算算法说明 V1.0

## 1. 目的与范围

本文说明 WCC4SM V0.9.3 中四种非参数峰位的实际计算方法：直接峰位（Direct peak）、插值峰位（Interpolated peak）、半高宽中心峰位（FWHM center）和质心峰位（Centroid）。内容以 `src/wc4sm_analyze_peak.m` 为准，适用于峰参数复核、波长定标、峰位差分析和峰位定义交叉验证。Gaussian fit 属于参数模型拟合，不在本文范围内。

## 2. 统一输入、峰窗与预处理

输入序列记为

\[
(x_i,y_i),\quad i=1,2,\ldots,N,
\]

其中，\(x_i\) 为严格递增的像素或波长坐标，\(y_i\) 为预处理后的光谱强度，\(x_c\) 为检测得到的近似峰位。程序先找出距离 \(x_c\) 最近的原始点 \(i_c\)，再按左右点数 \(L,R\) 截取：

\[
i_L=\max(1,i_c-L),\qquad i_R=\min(N,i_c+R).
\]

峰窗至少应有 3 个原始点。当前 GUI 首先在像素域分析，默认左右各取 5 个像素。

当前 GUI 在全局预处理之后，再使用峰窗两端点确定线性局部基线：

\[
b(x)=y_L+(y_R-y_L)\frac{x-x_L}{x_R-x_L},\qquad s_i=y_i-b(x_i).
\]

核心函数另支持常数基线（两端点强度的平均值）和无基线模式，主要供独立调用与测试使用。

若峰窗有 \(n\) 个原始点、插值因子为 \(F\)，则在 \([x_L,x_R]\) 内建立

\[
n_{dense}=(n-1)F+1
\]

个等间隔坐标 \(\xi_j\)，并得到净插值信号

\[
S_j=Y(\xi_j)-b(\xi_j).
\]

GUI 提供 PCHIP（推荐且默认）、Linear（比较）和 Spline（研究），默认插值因子为 20。原始强度按所选方法插值，局部基线始终线性插值。插值只提高数值定位的细分程度，不提高仪器的物理分辨率。

## 3. 四种峰位算法

### 3.1 直接峰位（Direct peak）

直接峰位取局部基线校正后原始采样点的最大值位置：

\[
x_{direct}=x_k,\qquad k=\mathop{\arg\max}_i s_i.
\]

它不使用加密插值，峰位只能落在原始采样坐标上。若多个点具有相同最大值，MATLAB `max` 返回第一个点。该方法简单、直接，但受采样间隔量化和最高点噪声影响较大。

### 3.2 插值峰位（Interpolated peak）

插值峰位取净插值信号的最大值位置：

\[
x_{interp}=\xi_q,\qquad q=\mathop{\arg\max}_j S_j.
\]

它仍是最大值法，但允许峰位落在原始像素之间，可减小直接峰位的采样量化效应；结果会受到插值方法、插值因子、峰形、噪声和峰窗影响。

若同一峰窗中存在多个已检测峰顶，GUI 会用相邻峰之间的实测谷底限制当前特征的插值搜索区间，避免强邻峰夺取当前峰位，并将该窗口标记为 `MultiPeak - position only`，提示复核。

### 3.3 半高宽中心峰位（FWHM center）

先取插值峰高的一半：

\[
h_{1/2}=\frac{1}{2}\max_j S_j.
\]

程序从插值峰顶向左右分别寻找半高交点，并在包围半高值的相邻网格点之间线性求交：

\[
x_{1/2}=x_1+(h_{1/2}-z_1)\frac{x_2-x_1}{z_2-z_1}.
\]

由左右交点 \(x_L^{(1/2)},x_R^{(1/2)}\) 得到

\[
x_{FWHMcenter}=\frac{x_L^{(1/2)}+x_R^{(1/2)}}{2},
\qquad
FWHM=x_R^{(1/2)}-x_L^{(1/2)}.
\]

该定义反映半峰高处的几何中心，与峰间分离和中心定位的传统表达相近。它对峰高噪声、基线和窗口截断较敏感；若任一半高交点不在窗口内，FWHM center 和 FWHM 均置为 `NaN`，结果标记为需要复核。

### 3.4 质心峰位（Centroid）

质心只使用净插值信号的非负部分：

\[
S_j^+=\max(S_j,0).
\]

在完整峰窗内采用梯形积分计算一阶矩：

\[
x_{centroid}=
\frac{\int_{x_L}^{x_R}xS^+(x)\,dx}
{\int_{x_L}^{x_R}S^+(x)\,dx}.
\]

代码的分子、分母均由 `trapz` 在加密网格上计算；若分母不大于零，质心为 `NaN`。质心代表峰内非负能量分布的重心，利用整个峰窗的信息，但对峰窗边界、局部基线、截断、邻峰混入和不对称拖尾较敏感。

## 4. 方法对比

| 峰位 | 使用数据 | 定义 | 主要优点 | 主要敏感因素 |
|---|---|---|---|---|
| Direct peak | 基线校正后的原始点 | 原始点最大值 | 简单、无插值模型 | 采样间隔、最高点噪声 |
| Interpolated peak | 净插值曲线 | 插值曲线最大值 | 减小像素量化效应 | 插值设置、局部峰形 |
| FWHM center | 插值曲线与半高交点 | 两个半高交点中点 | 体现半高几何中心 | 峰高、基线、交点和截断 |
| Centroid | 插值曲线非负部分 | 强度一阶矩 | 表征能量重心和不对称性 | 峰窗、基线、邻峰和拖尾 |

理想、充分采样且对称的孤立峰中，四种峰位应接近；存在欠采样、噪声、不对称、像差、拖尾或邻峰干扰时，它们可能产生系统差异。这些差异不只是“算法误差”，也反映峰形和应用定义的差别。

## 5. 派生峰位差

程序以 FWHM center 为中心参考，输出

\[
\Delta_{D-C}=x_{direct}-x_{FWHMcenter},
\]

\[
\Delta_{I-C}=x_{interp}-x_{FWHMcenter},
\]

\[
\Delta_{G-C}=x_{centroid}-x_{FWHMcenter},
\]

并输出 \(\Delta_{D-I}=x_{direct}-x_{interp}\)。这些差值可用于观察峰位定义随探测器位置或波长的系统变化。其中 Centroid 与 FWHM center 的偏离，可表征能量重心相对半高几何中心的不对称偏移。

## 6. 有效性与警告

- `x`、`y` 长度必须相同，至少包含 3 个有限数值点，且 `x` 严格递增；
- 截取后的峰窗至少包含 3 个原始点；
- 净插值峰高必须大于零，否则状态为 `Invalid`；
- 半高交点缺失时，FWHM center 与 FWHM 无效；
- 直接峰位落在窗口边界时给出警告；
- 若超过 10% 的原始窗口点低于插值峰高的 −1%，给出基线复核警告；质心和面积仍只使用非负信号；
- 无警告时状态为 `OK`，存在可继续计算的警告时为 `Review`。

得到有限峰位不等于该结果一定适合定标，仍应结合邻峰、峰窗、采样比、峰形和残差复核。

## 7. 与定标及交叉验证的关系

选择某种峰位拟合定标模型，相当于拟合

\[
\lambda=f_m(x_{method}),
\]

其中 \(m\) 为多项式阶次。训练和应用采用同一峰位定义时，得到该定义下的匹配性能；用一种峰位训练而用另一种峰位应用时，残差还包含峰位定义失配误差。

建议分别比较四种峰位的阶次扫描、Fit RMSE、LOO RMSE 和泛化间隙，并使用“峰位定义交叉验证”矩阵量化训练峰位与应用峰位的组合误差。在模型和后续应用中应保留 `PositionMethod`，避免模型定义混用。可面向不同任务分别保存模型，例如质心模型用于能量或积分相关分析，FWHM center 模型用于中心定位和峰间分离相关分析，Direct peak 模型用于简单快速测量。

峰位方法应由应用目标和验证结果共同确定，不应只依据某一次拟合的 Fit RMSE。

## 8. 主要输出字段

| 字段 | 含义 |
|---|---|
| `DirectPeakX` / `DirectPeakY` | 直接峰位及净峰高 |
| `InterpolatedPeakX` / `InterpolatedPeakY` | 插值峰位及净峰高 |
| `LeftHalfX` / `RightHalfX` | 左右半高交点 |
| `CenterX` | FWHM center |
| `CentroidX` | 质心峰位 |
| `FWHM` | 左右半高交点间距 |
| `PeakCenterDelta` | Direct peak − FWHM center |
| `InterpolationCenterDelta` | Interpolated peak − FWHM center |
| `CentroidCenterDelta` | Centroid − FWHM center |
| `RawInterpolationDelta` | Direct peak − Interpolated peak |
| `Status` / `Warnings` | 有效性状态与复核信息 |
| `Settings` | 峰窗、插值和基线设置 |

## 9. 实现与验证依据

- 核心实现：`src/wc4sm_analyze_peak.m`；
- GUI 调用和多峰窗口处理：`WCC4SM_V0_9_3.m`；
- 基础回归测试：`tests/TestPeakAnalysis.m`。

测试覆盖对称高斯峰、线性基线消除、峰窗截断和非法坐标。修改算法、默认参数或字段定义时，应同步更新测试、数据处理算法总说明和本文档。
