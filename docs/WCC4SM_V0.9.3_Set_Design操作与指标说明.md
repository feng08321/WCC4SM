# WCC4SM V0.9.3 Set Design 操作与指标说明

## 1. 功能定位

Set Design 用于从已经确认的完整标杆样本池中生成较小的波长定标子集，并始终在同一个完整样本池上评价各子集模型。它不替代寻峰、波长匹配和标杆池整理，而是在这些工作完成后分析“哪些点应保留”以及“不同子集是否形成实质不同的定标模型”。

页面提供两条相互独立的路线：

1. 规则生成：一次直接生成包含 Target K 个点的子集；
2. Backward Beam：从完整池开始，每次删除一个点，检查并确认后再进入下一层。

## 2. 页面表格

### 2.1 Full pool / manual selection

这是完整标杆池。每行代表一个已经匹配并可用于当前峰位定义的样本点。

- Use：用于 Manual selection；选中右侧候选后也会同步显示该候选的成员掩码；
- Rank：删除影响由强到弱的排序，1 为影响最强；
- Influence：删除该点后定标曲线变化的相对强度；
- Percentile：影响强度在完整池内的百分位；
- Quality：由峰对称性阈值产生的质量建议；
- Spacing：该参考波长与最近相邻参考波长的距离；
- Boundary：短波、长波边界或内部点。

### 2.2 Selected subset members

选中右侧任一候选集合后，本表只显示该集合实际包含的样本点，包括 Peak ID、像素、波长、影响排名、质量、局部间距和边界属性。这是确认“具体选了哪些峰”的主要入口。

### 2.3 右侧候选集合表

右表每行代表一个完整的子集模型，不代表一个样本点。

- State：Generated、Pending、Accepted 或 Rejected；
- Source：规则名称或 Beam 层级；
- Role：Performance、Diversity、Manual、Rule 或 Baseline；
- K：该集合包含的样本数；
- Deleted：从父集合删除的样本；
- All RMSE/P95/MAX：在固定完整标杆池上的残差统计；
- D RMS/D MAX：相对完整池基线模型的定标曲线距离；
- Cover：双阈值工程等价组编号。

## 3. 核心参数

### 3.1 Target K

Target K 是最终子样本数。

- 规则生成器会直接生成 K 点集合；
- Beam 从完整池开始逐层删除，达到 K 后停止；
- 三阶多项式数学上至少需要 4 点，但 4 点属于恰好插值，缺少冗余；
- 工程分析建议从 K=6 或更高开始，再通过全池残差、覆盖和独立数据验证决定是否继续缩减。

### 3.2 B perf

B perf 是每个 K 到 K-1 层中保留的性能候选数。候选首先按固定完整池的 All-point RMSE、P95、MAX 排序。

它控制对低残差路径的搜索宽度，不是样本数量。B perf 越大，越不容易过早丢失性能接近但删除路径不同的集合，计算量也越大。

### 3.3 B div

B div 是在性能候选之外保留的模型形态多样性候选数。软件比较候选模型在统一像素网格上的定标曲线，优先保留与已有性能分支差异较大的模型。

设置 B div 的目的不是追求较差模型，而是防止搜索过早收缩到一条局部路径。B div=0 时更接近纯性能贪心搜索；保留多个 Diversity 分支时才具有 Beam 的模型空间覆盖意义。

### 3.4 eps RMS 与 eps MAX

两个阈值共同定义工程等价模型：

$$
D_{RMS}leqarepsilon_{RMS}
quad	ext{且}quad
D_{MAX}leqarepsilon_{MAX}
$$

它们用于 ε-cover 分组，也作为 Diversity 距离的尺度。阈值越小，模型越容易被区分为不同组；阈值越大，更多模型会被视为工程等价。

默认值 eps RMS=0.01 nm、eps MAX=0.03 nm 是初始工程尺度，不应被理解为通用物理常数，应结合仪器分辨率、允许定标误差和重复测量稳定性调整。

### 3.5 统一指标解释

- Fit RMSE：只在当前子集的拟合点上计算，通常偏乐观；不能单独用于比较不同 K 的集合；
- All-point RMSE：把当前子集模型应用到固定完整标杆池后计算的均方根残差，是 Set Design 的主要统一比较指标；
- P95：完整池绝对残差的 95% 分位，用于观察大部分点的高位误差，同时比单一 MAX 更稳健；
- MAX：完整池最大绝对残差，用于发现最差局部位置；
- D RMS：候选模型与完整池基线模型在统一像素网格上的曲线差均方根；
- D MAX：两条模型曲线在统一网格上的最大绝对差；
- Influence：删除某点前后 LOO RMSE 变化量相对于完整模型 LOO RMSE 的比例。数值大表示模型对该点敏感，不等同于该点质量好或坏；
- Quality：当前由峰的质心位置与 FWHM 中心位置之差是否小于设定阈值得到，描述峰形对称性建议，不等同于模型影响强度；
- Cover：同时满足 D RMS 与 D MAX 阈值的一组工程等价模型。Cover 编号只是分组标识，不代表优劣排序。

因此 Influence、Quality 和残差指标分别回答“模型是否依赖该点”“峰形是否可信”和“子集模型在统一标杆池上表现如何”，三者不能相互替代。

## 4. 规则生成工作流

1. 点击 Refresh pool；
2. 设置 Target K；
3. 选择 Manual、Top-k influence、Maximin coverage、Locked boundary + coverage 或 Window 规则；
4. 点击 Generate rule set；
5. 在右表选中生成集合；
6. 查看 Selected subset members、覆盖图和完整池残差；
7. 将有价值的集合发送到 Add-One，或加入 Model Comparison。

规则生成适合比较具有明确物理含义的点位配置，不承担穷举最优组合的任务。

## 5. 分层 Beam 工作流

1. 建议首次使用 B perf=5、B div=5、eps RMS=0.01 nm、eps MAX=0.03 nm；
2. 点击 Initialize Beam，只建立完整池基线，不执行删除；
3. 点击 Calculate K-1，计算当前层所有唯一的一点删除候选；
4. 查看 Pending 候选的成员、覆盖、全池残差和模型距离；
5. 保留推荐勾选，也可以人工修改 Keep；
6. 点击 Confirm checked，只有此时才进入下一层；
7. 再次点击 Calculate K-1，继续删除一个点；
8. 重复直至达到 Target K。

如果每层只确认一个集合，该过程退化为人工辅助的逐步贪心删除。如果每层确认多个 Performance 和 Diversity 集合，则下一层会同时从多个父集合继续搜索。

## 6. 有意义的调参方式

建议进行 Beam 宽度敏感性比较：

1. 快速试算：B perf=3，B div=3；
2. 标准试算：B perf=5，B div=5；
3. 敏感性复核：B perf=10，B div=10。

如果增加宽度后，最优全池残差、主要 ε-cover 代表、边界点选择和高影响点保留关系基本稳定，可以认为当前 Beam 宽度已经足够。如果较大宽度持续发现明显更优或新的非等价模型，应继续扩大宽度或检查规则生成结果。

不建议仅凭单次最低 RMSE 自动确定最终集合。最终判断至少同时检查：

- All-point RMSE、P95 和 MAX；
- 残差随波长是否仍有趋势结构；
- D RMS 和 D MAX 是否明显偏离完整池模型；
- 短波与长波边界是否受到约束；
- 强影响点是否被保留以及删除后的物理解释；
- 峰形质量和局部波长聚集；
- 独立光谱或重复测量上的复核结果。

## 7. Session 与导出

Session 保存以下 Set Design 信息：完整影响档案、规则候选、Beam 节点与当前层、Pending 候选、父子路径、成员掩码、当前选中候选和全部参数。

Export results 输出：

- MAT：完整可恢复的 Set Design 数据；
- _pool.csv：完整标杆池及影响信息；
- _candidates.csv：候选模型指标；
- _members.csv：每个候选实际包含的样本点；
- _beam_layers.csv：Beam 各层候选数、接受节点和 cover 数。
- _beam_nodes.csv：接受节点的父节点、删除点、完整路径和评价指标。

## 8. 推荐使用原则

Set Design 的目标不是只找一个数学意义上的最低 RMSE 集合，而是识别少量性能良好、物理覆盖合理、对完整池模型偏离可控且具有不同代表性的候选集合。最终模型仍应经过模型比较、残差结构检查和独立数据验证后再应用。
