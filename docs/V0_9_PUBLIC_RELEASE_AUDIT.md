## 结论

公开发布的问题。出版社排版的参考论文 PDF 暂不应提交到公开仓库或打入公开
发布包，除非作者已从出版协议或论文页面确认允许再次分发。

## 论文 PDF 的处理

文件：

`refer-paper-2026-multi-parameter-wavelength-characterization-of-array-spectrometers-under-near-limit-sampling-conditions.pdf`

该文件是 SAGE / *Applied Spectroscopy* 出版社排版版本。PDF 内未发现明确的
Creative Commons 许可标记，公开检索也未找到该论文的再分发许可说明。因此：

- 可以在说明书、README 和软件中引用题名、作者、期刊与 DOI。
- 可以在作者有合法访问权的本机 `docs/` 中供本人使用。
- 在确认出版协议、开放获取许可或取得出版社许可前，不提交到公开 GitHub，
  不放入公开 Release ZIP。
- WCC4SM 的 Apache License 2.0 不覆盖该论文 PDF。

## 发布前最终检查

1. 决定仓库公开前，再确认论文的出版许可；未确认时排除该 PDF。
2. 从干净检出目录构建发布 ZIP，防止把本机未跟踪文件和 `result/` 带入包内。
3. 检查 ZIP 文件清单并计算 SHA-256。
4. 对最终 EXE 执行一次启动、数据加载、定标、会话保存/恢复和 PDF Help 冒烟测试。
5. 保持已发布的 `v0.9` 标签不变；文档更新使用后续补丁标签或单独文档版本。
