WCC4SM V0.6.0
Date: 2026-08-03

Major update
------------
1. Adds SAVE SESSION and LOAD SESSION to the header.
2. Saves spectrum/dark data, detected and confirmed peaks, reference lines,
   calibration pairs, initial/final/history/applied models and major UI settings.
3. Captures operator, instrument and reference-wavelength provenance before save.
4. Loads and validates the complete session before replacing current state.
5. If loading or view restoration fails, the previous in-memory state is restored.
6. Rebuilds tables, model comparison, residual/LOO views and the applied wavelength
   axis after successful loading.

Retained baseline
-----------------
All V0.5.4 modular spectrum, preprocessing, calibration, LOO and calibrated-
performance behavior is retained. WCC4SM_V0_5_4.m remains unchanged as the
fallback baseline.

Validation required
-------------------
Run all 33 non-GUI tests, then complete a save-close-restart-load-continue-save
workflow using a real calibrated project.
